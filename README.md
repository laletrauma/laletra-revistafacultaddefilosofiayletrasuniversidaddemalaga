# La Letra

**Revista universitaria** de la Facultad de Filosofía y Letras de la Universidad de Málaga.

Esta es la galería de todos nuestros números publicados. **Pincha en cualquier portada** para leer el PDF completo.

## 📖 Cómo usar

1. Abre [la galería de números](https://lidiaayalalaguna111.github.io/La-Letra/) (o abre `index.html` localmente)
2. Haz clic en cualquier portada
3. ¡Lee el PDF!

## 📁 Estructura

```
ejemplares/
├── numero-1/

```
